直播吧 Modern 是一个为直播吧首页重新设计的开源 Chrome 主题扩展。

它不改变直播吧的内容和功能，只重做页面的视觉层：更宽的版心、更清晰的层级、更舒服的留白，以及一套真正适合长时间浏览的浅色 / 深色主题。

【主要功能】

• 精简顶部导航（默认开启）
只保留「首页」入口，其他顶部菜单会收起，让首页更干净。想恢复完整导航时，在扩展弹窗里关闭这个开关即可。

• 跟随系统 / 浅色 / 深色
点击导航右上角的按钮切换主题，选择会自动保存；深色模式覆盖首页的主体、卡片、赛程、榜单和弹窗。

• 比赛日速览
从首页现有赛程中整理出可横向浏览的 Match Center，快速查看今日对阵，并可跳回完整赛程。

• 重新设计的首页模块
足球视频、篮球视频、足球资讯、篮球资讯、完赛比分、电竞资讯、球队榜和球员榜使用统一的卡片、标题与间距。

• 只改首页
首页中的视频、资讯、直播、比分等链接仍然进入直播吧原站页面；扩展不会给这些子页面注入主题。

• 随手开关
在扩展弹窗中关闭主题或精简导航，页面立即恢复原样，无需刷新。

• 响应式
适配 1440 / 1280 / 1024 / 768px 桌面宽度，窄屏下自动重排。适用于 Chrome 111 及以上版本的桌面浏览器。

【轻量与透明】

不使用分析、广告或遥测；扩展本身不发起外部请求。只申请 storage 权限，用于保存主题、启用状态、精简导航和首页赛程开关，不读取 Cookie、账号或表单内容。

【说明】

这是非官方、MIT 协议的开源项目，与直播吧没有隶属关系。页面内容、Logo 和图片仍来自直播吧及其 CDN。
